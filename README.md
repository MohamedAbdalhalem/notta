# 📝 Notes App

A simple **Notes App** built with **Next.js**.  
Users can register, log in, and manage their personal notes with full CRUD functionality (Create, Read, Update, Delete).

---

## 🚀 Features
- User authentication (Register & Login)
- Dark/Light mode support
- Add, view, edit, and delete notes
- Modern UI using Material UI & Styled Components
- State management with Redux Toolkit
- Form validation with React Hook Form

---

## 🌍 Live Demo
Check it out here: [Notes App on Vercel](https://notta-one.vercel.app/)

## 🛠️ Tech Stack
- Next.js 15
- React 19
- Redux Toolkit + React Redux
- Material UI
- Styled Components
- React Hook Form
- Axios
- js-cookie
- next-themes
